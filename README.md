# The Guide to SEO

A heavily-optimized, static **Guide to SEO** — and a working demonstration of the SEO it teaches
(semantic HTML, one H1/page, meta + canonical + Open Graph, JSON-LD Article + BreadcrumbList,
sitemap.xml, robots.txt, no JavaScript, tiny CSS → Core Web Vitals green by construction).

## How it was built (cloud-PM + local-dev system)
- **Content & architecture:** written by the cloud model (Claude), grounded in primary sources
  (Google Search Central, web.dev Core Web Vitals).
- **Code generation:** the site CSS was generated by a **local LLM** (Qwen2.5-Coder-7B via Ollama)
  under a tight spec, then verified automatically before it was accepted.
- **Generator:** `build.py` renders `content/*.md` into optimized static HTML in `docs/`.

## Build
```
python3 build.py      # -> docs/ (8 pages + sitemap.xml + robots.txt)
```

## Deploy (GitHub Pages)
Enable Pages with source = **main / /docs**. Live URL: `https://connor-enge.github.io/seo-guide/`.
(Requires the repo to be public, or a GitHub plan that allows Pages on private repos.)

## Structure
- `content/*.md` — the guide, one file per section (front-matter + markdown)
- `templates/base.html` — the SEO-optimized page shell
- `assets/style.css` — lightweight responsive styling (local-dev generated)
- `build.py` — static site generator (SSG) with all on-page SEO baked in
