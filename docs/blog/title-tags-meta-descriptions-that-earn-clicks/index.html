Writing Title Tags and Meta Descriptions That Earn Clicks

Published 2026-08-07 · by Connor Enge · 4 min read

  • Why Google rewrites your titles
  • What actually makes a good title tag
  • Meta descriptions function as a pitch
  • Writing descriptions that earn clicks
  • Length considerations for display
  • Key takeaways

The title link and snippet shown for a page in search results often form the first point of contact with a searcher. These elements help determine whether a result receives a click, which makes writing them deliberately useful even though they remain under partial control. Google draws the displayed text from several page sources and may override the supplied tags when it finds better matches.

The title tag is a preference, not a guarantee¶

Google generates the title link shown in results automatically. It pulls from the content of the title element but also considers the main visual title on the page, heading elements such as h1, og:title meta tags, other prominent text, anchor text pointing to the page, and WebSite structured data. Because multiple signals compete, the supplied title tag functions as one input among several rather than a fixed command. Changes to the title tag require a recrawl and reprocessing before they appear, a process that typically takes days to weeks.

Why Google rewrites your titles¶

Google replaces supplied titles when they fail to match visible content or user expectations. A half-empty title such as "| Site Name" leads Google to substitute a heading that supplies the actual product or page name, resulting in "Product Name | Site Name". An obsolete title such as "2020 admissions criteria" gets replaced when the page body displays the current year. Inaccurate or stuffed titles such as "Giant stuffed animals, teddy bears, polar bears - Site Name" are often shortened to the more relevant core phrase "Stuffed animals - Site Name".

Repeated boilerplate titles across many pages also trigger substitution. When every season of a series carries the identical title "My so-called amazing TV show", Google inserts distinguishing details such as "Season 2". Multiple equally prominent headings on one page can cause Google to select the first heading by default; designating one heading as visually dominant clarifies the intended main title. Language mismatches between the title tag and the page body likewise prompt replacement from the visible text.

What actually makes a good title tag¶

Every page should carry a title element. The text inside it should remain descriptive and concise while avoiding vague labels such as "Home" or "Profile". Keyword repetition such as "Foobar, foo bar, foobars, foo bars" reduces clarity and increases the chance of rewriting. Brand names belong at the start or end, separated by a single delimiter such as a hyphen or pipe, rather than repeated on every page.

A single dominant h1 placed early and styled distinctly helps Google identify the primary title. The title should match the primary language of the page content. These practices align with broader on-page SEO work that ensures headings and visible text reinforce one another.

Meta descriptions function as a pitch¶

Google constructs the snippet shown beneath the title link primarily from page content. The algorithm selects and emphasizes portions that best match the current query, which can produce different snippets for different searches. It uses the meta description only when that supplied text supplies a more accurate summary than the extracted page content. The meta description therefore influences click decisions without serving as a direct ranking signal.

Writing descriptions that earn clicks¶

Unique descriptions for each page prevent dilution across similar content. Home and aggregation pages can use site-level text while individual pages receive page-level detail. Relevant specifics such as author and date on a blog post or price and manufacturer on a product page improve usefulness. The text does not need to form a single sentence and should stay readable rather than packed with repeated terms.

A keyword list such as "Sewing supplies, yarn, colored pencils, sewing machines, threads, bobbins, needles" is less likely to appear than a clearer alternative: "Get everything you need to sew your next garment. Open Monday-Friday 8-5pm, located in the Fashion District." A description limited to "Mechanical pencil" offers little information compared with one that states the product's key attributes in a full sentence. These choices reduce overlap with common SEO mistakes that treat the meta description as a place to repeat target phrases.

Length considerations for display¶

Google states no fixed character limit for either the title element or the meta description. The displayed title link and snippet are truncated only as needed to fit the width of the device showing the result. In practice, many desktop results show roughly the first 50-60 characters of a title link and the first 150-160 characters of a description before cutting the remainder. Placing the most important words early in each field therefore improves the chance that the visible portion remains informative on both desktop and mobile screens.

Advanced controls exist for cases where automatic snippets are undesirable. The nosnippet meta tag can suppress the description entirely, max-snippet can set a character cap, and the data-nosnippet attribute can exclude specific page sections.

Key takeaways¶

  • Supply a unique, descriptive title element and meta description on every page while recognizing that Google may still select different text.
  • Make one heading visually dominant, keep titles concise, and avoid boilerplate or repetition that triggers automatic replacement.
  • Write meta descriptions as readable summaries that include specific page details rather than keyword lists.
  • Front-load essential information within the first 50-60 characters of the title and 150-160 characters of the description because truncation occurs at device width.
  • Test changes after allowing time for recrawl, and review results against how Google discovers and ranks pages to confirm the displayed text matches intent.
